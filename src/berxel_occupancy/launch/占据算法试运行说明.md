# P100R 占据算法试运行

代码目录：`/home/y/ros2_ws/src/berxel_occupancy`

这是参考 SCAN-Planner 概率占据建图原理的独立 C++ ROS 2 实现，尚未接入导航规划器。

## 启动

先关闭 HawkDepth 和其他占用相机的程序，然后在终端执行：

```bash
source /opt/ros/humble/setup.bash
source /home/y/ros2_ws/install_y/setup.bash
source /home/y/berxel-sdk/berxel_set_env.sh
ros2 launch berxel_occupancy occupancy.launch.py
```

默认启动 P100R、占据节点和 RViz。按 Ctrl+C 停止。

RViz 中橙色是全部占据体素（含地面），红色是离地 0.15～1.8 米的障碍体素；空闲空间和二维投影默认关闭，可以在 Displays 勾选。

配置源文件：`/home/y/ros2_ws/src/berxel_occupancy/config/occupancy.yaml`。可复制配置到自己的路径，然后用 `params_file:=/绝对路径/occupancy.yaml` 启动；直接修改源配置后需要重新编译安装。

## 当前参数和能力

相机高度 0.90 米、向下俯视 34°；10 厘米体素、5 Hz、像素步长 4，有效光轴深度 0.2～3 米。

有效深度端点增加占据证据，射线经过区域增加空闲证据；无效深度不清空地图。未观测保持未知。地面保留在原始占据地图中，障碍显示按高度筛选。

## 验证

2026-10-31 已编译、通过 12 项核心行为检查及 ROS 合成输入测试，并连接真实 P100R 复测。

14 秒采样收到 70 次更新，约 5.00 Hz；末帧有 928 个占据体素、2836 个空闲体素、333 个高度筛选障碍体素。数量随现场变化，表示体素数量，不是物体个数。

保守二维投影末帧为 159 格占据、1641 格未知、0 格空闲：只有整列指定高度都明确空闲才标为空闲，因此即使三维地图有空闲体素，二维也可能仍未知。

## 限制

当前相机必须固定；移动后需要停止重启以清空旧地图。未接入里程计、动态位姿、障碍膨胀或避障控制。没有完整 CPU 对照测试，不能据此断言比原算法省 CPU。相机高度和角度误差会影响地面附近的障碍显示。

实机测试结束后已停止测试进程，当前没有留后台相机占用。

## RViz 视角与相机标记（更新）

已补上原配置遗漏的 Move Camera 工具，并将其设为默认工具；增加 Views 面板、地图坐标轴和 `/occupancy/camera_reference` 相机参照。

请在原启动终端 Ctrl+C，再执行相同启动命令以加载新版本。

- 鼠标放在三维画面内：左键拖动旋转，中键拖动平移，滚轮缩放。按 Esc 回到 Move Camera。
- 青色球 `P100R camera`：相机光心，默认 `(0,0,0.90)` 米。
- 青色竖线：相机至地面的高度；绿色箭头：光轴朝向，默认向前下俯34°。
- 灰色地面网格：z=0，每格0.5米。地图坐标轴：X红色向前，Y绿色向左，Z蓝色向上。
- 橙色体素：测得的占据几何，包括地板；红色：离地0.15～1.8米的占据体素。

已验证安装配置、相机Marker数据、参数化方向和持久订阅接收；实际原生RViz窗口的鼠标拖动尚未直接操作验证。
