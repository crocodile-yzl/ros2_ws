## 新增纯 C 包 d435i_video_c

- 路径 `/home/y/ros2_ws/src/d435i_video_c`：ament_cmake + 纯 C（`src/d435i_video_c.c`），
  采集用 librealsense C API（`rs2_*`），发布用 `rcl` C API + `sensor_msgs__msg__Image`。
  话题与 Python 版一致：`/video`(bgr8) + `/video/depth`(16UC1，可对齐)。
- **CMake 关键点**（照着写可省几轮返工）：
  - `target_link_libraries` 用 `${rcl_LIBRARIES}`，写裸 `rcl` 会变成 `-lrcl` 链接失败；
    不同发行版导出方式不同，用 `if(TARGET rcl::rcl)` 兜底。
  - 必须自己 `target_include_directories(${rcl_INCLUDE_DIRS}
    ${rosidl_runtime_c_INCLUDE_DIRS} ${sensor_msgs_INCLUDE_DIRS})`，否则
    `rcl/error_handling.h` 找不到。
  - 源码是 .c 但要 `LINKER_LANGUAGE CXX`，因为 rosidl/rcl 依赖里有 C++ 运行时。
- launch 传布尔用 `--depth=true`（optional_argument），不能拼空 token；
  `--serial` 也必须 optional_argument 且空值跳过，否则会把后面的 `--depth=true`
  吞成序列号（这个 bug 实测复现过）。
- 宿主验证（Humble + 系统 librealsense2 2.58）：零警告编译通过；`--help`、
  无设备退出码 1、launch 参数拼接都正确。**真机未验证**（宿主无相机）。
- 宿主编译踩坑：CMake 默认抓到 3.13（无 catkin_pkg），要加
  `--cmake-args -DPython3_EXECUTABLE=/usr/bin/python3`；工作区是 root 所有，
  构建要 `--build-base/--install-base` 指到可写目录。
- 容器里编译需要 librealsense2 的 CMake config：`librealsense2-dev` 或
  `ros-jazzy-librealsense2`。
